How Black Mode thinks

From prompt to code in four steps, all on your machine.

01

Intent Classification

Your prompt is analyzed locally to determine task type: generation, refactoring, debugging, review, or documentation. This classification takes under 5ms with zero network calls.

02

Context Retrieval

Relevant code is pulled from your local vector index. File dependencies, type definitions, test patterns, and commit history are assembled into a rich context window.

03

Model Routing

The router selects the optimal model based on task complexity and available resources. Simple completions go to TinyLlama, complex generation to CodeLlama, reasoning tasks to Mistral.

04

Response + Audit

Generated code is returned with inline diffs. Every interaction is logged to the local audit database with cryptographic signatures. You own the complete history.
